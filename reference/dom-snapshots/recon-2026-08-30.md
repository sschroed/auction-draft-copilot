# ESPN draft room DOM recon — live mock, 2026-08-30

## Nomination / on-block area
`div[data-testid="player-selected"]` (inside `div.pickArea`)
- player info: `.player-selected__player-info-container` → `span.playerinfo__playername`, `span.playerinfo__playerpos`
- default bid: `span.player-default-bid`

## Bidding form
`div[data-testid="bidding-form"]`
- current bid: `div.current-amount` → text `Current offer: $56`
- ESPN's computed max for me: `div.manual-bid` → text `Manual offer (max $189)`
- (bid button: `button.bid-player__button` "Offer $57" — never touched, read-only)

## Bid history (who holds the high bid)
`ul.bid-history__list li.bid` → `"$56 <team name>"`

## Pick history feed (sales)
`li.pick-message__container` rows:
```html
<li class="... pick-message__container ...">
  <span class="playerinfo__playername">Puka Nacua</span> /
  <span class="playerinfo__playerteam">LAR</span>
  <span class="playerinfo__playerpos ttu">WR</span>
  <div class="... pick-info ...">$58<span> - Some Team</span></div>
</li>
```
→ price + buying team live in `.pick-info` ("$58 - Some Team").

## Pick train (per-team cards)
`li.picklist--pick > div[data-testid="auction-pick"] > div.content`
- **my team's card gets modifier class `auction-pick-component--own`** ← "is it me?" hook
- remaining budget: `div.cash` ($200); current bid shown as `div.bid-amount`
- states seen: `.autopick`, `.auction-pick-component--selecting`

## Notes
- Classes are `jsx-*` (styled-jsx hashes) + stable BEM-ish names; selectors built on the stable fragments only.
- Player tables use `fixedDataTable*` classes (not needed for detection).
